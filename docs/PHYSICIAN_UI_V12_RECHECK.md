## 問題 1／高：頁首宣稱感染適用性已有支持，但 0 項有證據且逐藥明示未通過獨立複核

**重現步驟**

1. 開啟指定 run 的分析結果。
2. 查看逐藥決策表上方摘要。
3. 展開任一藥品的 `未完成項目`，例如 amoxicillin_clavulanate。
4. 到證據與流程確認 Audit 狀態。

**實際所見**

- 頁首：`0 項有證據的待審閱選項（包含於待確認）。感染適用性已有支持，病人風險仍需核對；不能直接接受為完成建議。`
- amoxicillin_clavulanate 未完成項目：`引用未支持 · 感染適用性 · 感染適用性尚未通過獨立複核`
- 流程：`06 引用獨立複核 · 無可複核聲明，未執行`

**醫師可能如何誤解**

`感染適用性已有支持` 是肯定句，會讓人以為感染部位、病原條件及引用適用性已完成核對。但同一頁顯示 0 項有證據，逐藥也明說感染適用性尚未通過獨立複核，Audit 更沒有執行。這是畫面內直接矛盾。

**建議**

- 當有證據待審閱選項為 0，隱藏 `感染適用性已有支持`。
- 改為依實際狀態顯示：`感染適用性尚未通過獨立複核；病人風險 Agent 已回報結果，但整合未完成。`
- 若該句原本只是分類說明，改成條件式提示，不要寫成此次 run 的已完成事實。

## 問題 2／中高：列內「本次核對未發現風險」與折疊內的同面向輸入省略並列，仍可能被掃讀成已排除風險

**重現步驟**

1. 在逐藥表查看 amoxicillin_clavulanate。
2. 先讀臨床風險欄。
3. 再展開 `amoxicillin_clavulanate：未完成項目`。

**實際所見**

- 臨床風險欄：`本次核對未發現風險`
- 分項：`過敏：本次核對未發現風險`、`腎功能：本次核對未發現風險`、`交互作用：本次核對未發現風險`
- 折疊的未完成項目同時列出：
  - `輸入片段被省略 · 過敏 · 查詢或輸入片段尚未完整提供`
  - `輸入片段被省略 · 腎功能 · 查詢或輸入片段尚未完整提供`
  - `輸入片段被省略 · 交互作用 · 查詢或輸入片段尚未完整提供`

**醫師可能如何誤解**

`本次核對未發現風險` 比單純的 `無風險` 精確，也有整體待確認提示；但同面向的輸入並未完整提供，而這項限制預設折疊。快速掃表時仍可能理解成過敏、腎功能與交互作用已完整排除風險。

**建議**

- 同一面向若有輸入片段省略，列內狀態改成 `本次已讀片段未見風險；輸入不完整`。
- 在臨床風險欄直接顯示未完成徽章，不要求展開最右側內容後才知道限制。
- `本次核對未發現風險` 僅用於該面向輸入完整且來源核對完成的情況。

## 次要可讀性問題

amoxicillin_clavulanate 的未完成項目中，`輸入片段被省略 · 整體 · 查詢或輸入片段尚未完整提供` 完全相同地出現兩次，且沒有來源 Agent 欄位。若兩筆分別來自 Evidence 與 Clinical，建議顯示來源；若來源相同，應合併。

## 兩項文案修正複驗

使用同一 run，只複驗前述兩項重要問題。兩項均已修正，未發現新的實質誤導或操作阻擋。

### 通過：第二層頁首改為定義，不再宣稱本 run 已有感染支持

修正後實際文字：

`0 項有證據的待審閱選項（包含於待確認）。此層僅收錄感染適用性已獨立核對、仍有風險缺口的項目；不能直接接受為完成建議。`

此句現在說明第二層的收錄條件，沒有再把「感染適用性已有支持」寫成本 run 的事實。搭配 0 項計數，可以理解為本 run 沒有任何項目進入該層，與 Audit 未執行及逐藥「感染適用性尚未通過獨立複核」不再矛盾。

### 通過：Clinical 結果已明示為初評，輸入省略限制直接顯示

以 amoxicillin_clavulanate 為例，修正後臨床欄直接顯示：

- `臨床初評：本次核對未發現風險`
- `尚未完成整體核對，不能解讀為已排除風險。部分來源片段未提供，請查看未完成項目。`
- `以下為臨床 Agent 初評；是否通過完整核對，以獨立複核為準。`
- `過敏初評：本次核對未發現風險`
- `腎功能初評：本次核對未發現風險`
- `交互作用初評：本次核對未發現風險`

相同限制也直接出現在其他藥品列，包括狀態為 `需注意` 或 `未知` 的項目。使用者不需展開未完成項目，就能知道「本次未發現」只是 Clinical 初評，部分來源片段尚未提供，也不能解讀成已排除風險。

原問題 1 與問題 2 可標記為已修正。
