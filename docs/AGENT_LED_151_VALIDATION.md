# 1.5.1：付費前的來源與時間配置修正

2026-10-09（Asia/Taipei）。使用者要求先修已知引用錯配、替最後獨立複核保留時間。本輪完成本機驗證，未執行付費模型分析。

## 改了什麼

- 來源檢查讀原始產品標題，避免「DailyMed imipenem」簡稱掩蓋 RECARBRIO 複方成分。相同成分的鹽類／晶型不自動當成另一個複方。錯藥的劑量表也會標為待確認。
- 過敏、腎功能與交互作用必須有同一藥品所選原文的對應內容，不能把某藥的名字與另一藥的風險文字拼成支持。宣稱「無需調整劑量」須有具體劑量調整原文，不能以一般老年監測、肝功能、病人衛教等替代。一般腎功能觀察的「沒有變化」也不是「不用調整劑量」。
- 中文交互作用聲明／下一步中可辨識的羅馬字藥名須出現在同藥所選原文；覆蓋 valproic acid 前置、後置、括號別名等已知錯配。這是有限的來源檢查，不是完整藥名辨識或藥物交互作用規則引擎。
- 上述檢查接入 Evidence、Clinical、獨立 Audit 分項與注意事項；失敗分項降級並保留理由，其他有效結果保留。前端及匯出保留核對缺口；既有逐藥醫師決策照常可用。
- 預設全程上限由 480 調為 780 秒（13 分鐘），正常六次模型呼叫、全程最多八次不變。前四角色各上限 60 秒，整合與 Audit 各 180 秒；先保留剩餘角色的額度，檢索和補正僅使用可用時間。明確設定更小全程上限時按比例縮小保留額度，不偷偷延長使用者設定。
- 傳給檢索的截止時間扣除後續角色保留時間；Ollama 查詢使用本請求的 provider 複本及縮短的 HTTP timeout，逾期回覆不採用，不改其他請求的設定。分析期間不臨時補建缺少的向量索引，會顯示可操作的索引未備妥原因。其他三模式與手動搜尋保留原本補建索引行為。
