## DEMO 步驟

1. 後端與前端啟動後選 multi-agent，使用明確選定的病例版本。只有在取得新的付費／外送授權後才執行 live；mock 只代表流程測試。
2. 分析完成後查看逐藥表：完整核對候選、有證據的待審閱選項、其他待確認、不建議／未選入各自分组。同一藥不因同時存在 pending 與 review_options 而重複顯示。
3. 展開第二層的「未完成項目」，說明感染支持已核對，但哪些風險或來源仍未完成；未測AST不能稱敏感。
4. 展開證據與複核表，分別查看五個分項、原始引用及具體理由。某一項未知不代表其他項沒有結果；模型的 supported 本身也不等於專家確認。
5. 先核對畫面「分析當時病例」的版本與模型，再從「需要補充或確認」按「查看此步驟」／「查看錯誤步驟」，確認跳到對應Agent。查看 Agent 詳細紀錄與檢索表，示範各風險查詢、被省略片段與補正次數。有補正時總呼叫數不能超過八次。
6. 只有完整候選可進入接受／修改；第二層先補充資訊或重新分析。沒有完整候選時不要演示接受不存在的建議。
7. 匯出並核對 result_tier、review_options、分項複核與 blockers。歷史 v10 保持其原來 1.3.6 結果，不能當作 1.4.0 live。
